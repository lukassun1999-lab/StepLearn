## 开头的话（请家长先读这一段）

拾阶而上（StepLearn）是一款英语学习辅助工具：您上传孩子的试卷，系统识别错题、分析薄弱点、生成练习和报告。

**本服务的主要使用者是您的孩子——未成年人。** 因此，我们把孩子的学习数据当作最重要的事情来对待：只收集学习所必需的，不拿去做任何推荐和广告，您可以随时要求我们彻底删除。这份政策用平实的语言写清楚每一个细节，请您在使用前完整阅读。

## 1. 我们收集哪些个人信息

### 1.1 账号与身份信息（注册学生账号时）

| 信息项 | 说明 |
|--------|------|
| 手机号 | 注册与登录账号、接收短信验证码 |
| 登录密码 | **仅保存不可逆的加密摘要**，我们不保存、也无法还原您的明文密码 |
| 姓名 / 昵称 | 用于在报告与错题本中标识您的孩子 |
| 年级 | 用于匹配题目难度与知识体系 |
| **出生年份** | **仅收集年份（不含具体生日）**，用于判断孩子是否不满十四周岁，以决定是否需要取得您的**单独同意** |
| 教材版本 | 用于对齐学校教学进度 |
| 班级码（如老师提供） | 用于加入老师所在班级，年级以班级为准 |

> 家长为免登录使用时，无需提供上述账号信息；系统会为该学生生成专属链接标识（随机字符串），用于您访问孩子的学习页。

### 1.2 家长联系信息（选填，由家人在建档时提供）

| 信息项 | 说明 |
|--------|------|
| 家长姓名 / 微信 / 手机号 | 用于服务沟通、学习反馈与紧急联系；您不填写不影响使用 |

### 1.3 家长提供的学习材料（使用功能时上传）

| 信息项 | 说明 |
|--------|------|
| 试卷照片 / PDF / Word | 核心功能输入，用于 OCR 识别与错题分析 |
| 答题卡（可选） | 孩子的实际作答，用于对比批改 |
| 标准答案（可选） | 老师提供的标准答案，用于提高批改准确性 |

### 1.4 学习过程中产生的数据

| 信息项 | 说明 |
|--------|------|
| 错题本与批改记录 | 每道错题的题目、孩子作答、正确答案、解析、知识点 |
| 掌握度与复习记录 | 练习作答、掌握进度与复习安排（用于"错题越读越薄"） |
| 错因画像与跨周变化 | 对错题原因的归因结果，以及按周对比的变化轨迹 |
| 长期学习画像 | 跨月沉淀的"学习特点、哪类错因反复出现、哪种讲法对您孩子有效" |
| 成绩记录 | 您录入或系统记录的分数及其趋势 |
| 打卡与坚持日记 | 学习打卡日期、内容与时长 |
| 元认知复盘 | 复盘时孩子与家长填写的心情评分与反思文字 |
| 成就与徽章 | 学习里程碑与获得的徽章记录 |
| 生成的报告与文件 | 诊断报告、分析报告、批改反馈、周报、月度总结、练习卷、海报 |
| 任务中间产物 | 为支持任务中断后继续处理而暂存的识别文本与分析结果 |

### 1.5 学习特质信息（选填，建档时由家人填写）

为让练习与建议更贴合孩子，我们**在您愿意填写时**收集下列信息；**全部可选，不填写不影响核心功能**：

- 基本信息补充：性别、学期、学业目标、选科情况；
- 时间安排：每周可用时间、精力高峰时段、可投入的英语练习时长；
- 英语学情：近期分数、薄弱领域、薄弱题型、失分原因、困惑的语法点、已有学习资源、词汇方向；
- 学习特质：学习风格、学习媒介偏好、词汇习惯、注意力方面的困难、对您孩子有效/无效的方法、英语学习自我认知、阶段小测评结果；
- 目标与支持：目标时间线、一个月目标、家长可参与程度、是否需要陪伴监督、学习环境；
- 孩子的心声：最不喜欢的任务、偏好的练习强度、期望用英语做什么。

### 1.6 交易信息

付费时，我们收集支付金额、套餐类型、对应学生、收款登记时间等订单信息，用于额度登记与对账。**我们不收集、也不存储您的银行卡号或支付账户密码**，收款通过【待填：收款方式说明】人工登记完成。

### 1.7 操作与运行日志

| 信息项 | 说明 |
|--------|------|
| 操作日志 | 建档、上传、生成、修改、删除、授权与撤回等操作的记录，用于安全审计与故障排查 |
| AI 调用记录 | 调用次数、所用模型、用量与费用，用于成本核算与故障定位（不含超出上述范围的额外内容） |

### 1.8 我们不收集的信息

我们不需要且不会主动收集：孩子的身份证号、人脸等生物识别信息、精准地理位置、通讯录、健康信息。如某项功能未来确需收集上述信息，我们将依法另行取得您（监护人）的单独同意。

## 2. 我们为什么收集（目的与必要性）

| 信息 | 用途 | 不提供会怎样 |
|------|------|--------------|
| 手机号、密码 | 注册与登录账号 | 无法注册学生账号（家长免登录使用不受影响） |
| 姓名/昵称、年级、教材版本 | 标识学生、匹配学段与教材 | 无法注册学生账号 |
| 家长联系信息 | 服务沟通与学习反馈 | 不影响使用 |
| 试卷/答题卡/标准答案 | OCR 识别、错题分析、生成练习 | 无法提供核心批改功能 |
| 学习过程数据（1.4） | 生成报告、追踪掌握度、安排复习 | 无法提供核心功能 |
| 学习特质信息（1.5） | 让练习与建议更贴合孩子 | 不影响使用，但针对性会下降 |
| 操作与运行日志 | 保障账号与数据安全、排查故障 | 由系统自动生成，不涉及您主动提供 |
| 交易信息 | 额度登记、对账、开具凭证 | 无法完成付费服务 |

**拒绝提供非必要信息，不影响您使用基础功能。** 例如：您不上传可选的"标准答案"，批改功能仍可使用，只是准确性可能下降；您不填写真实姓名，使用昵称即可；您不填写第 1.5 条的学习特质信息，练习仍会生成，只是个性化程度降低。

3.2 **存储期限：**

- 您申请删除后，我们执行级联硬删除（见第 6.4 条）；
- 删除后仅保留**匿名化**的支付对账与审计记录，该等记录已无法关联到具体个人，保留期限为【待填：对账与审计记录保存期限】，以满足财务与法律要求。

## 4. 我们如何使用第三方服务（共享与委托处理）

4.1 **第三方大模型 API（委托处理）：** 为完成 OCR 识别、错题分析与练习生成，我们会将您上传的试卷图像或识别后的文本内容，通过 API 委托**杭州深度求索人工智能基础技术研究有限公司（DeepSeek 开放平台，中华人民共和国境内服务商）**处理。**我们要求该服务商按下列方式处理，并正在以书面协议明确该等义务：**

- 仅能为完成本服务目的处理相关数据，不得进行非授权的使用或披露；
- **不得将相关数据用于模型训练、不得用于任何推荐或广告用途**；
- 处理完成后按约定清除或返回数据。

我们仅使用该服务商**面向开发者的 API 服务**，**不会将孩子的数据输入任何面向公众的对话式产品**（该服务商面向公众的对话产品另有"数据用于优化体验"的开关机制，本服务不适用该场景）。

**在完成上述书面协议之前，我们不会将真实学生的试卷数据提交该服务处理。**

4.2 **云服务商：** 文件与数据库存储于【待填：云服务商名称，如腾讯云】，云服务商仅提供基础设施，不接触数据的内容用途。

4.3 **除上述两类外，我们不会向任何第三方共享您孩子的个人信息**，下列情形除外：取得您的单独同意；法律法规或司法、行政机关依法要求；保护重大人身财产安全所必需。

4.4 **转让与公开披露：** 我们不会将您孩子的个人信息转让给任何第三方，亦不会公开披露您孩子的个人信息；法律法规另有强制规定的除外。

4.5 **跨境传输：** 目前本服务的全部数据处理均在中华人民共和国境内完成，不涉及跨境传输。如未来因技术方案调整涉及跨境，我们将依法履行告知义务，并**另行取得您的单独同意**。

## 5. 未成年人个人信息专门章节

> 依据《个人信息保护法》第二十八条、第三十一条及《未成年人网络保护条例》第三十二条，本章节是本政策的专门规则，与正文具有同等效力。

5.1 **敏感个人信息定性：** 不满十四周岁未成年人的个人信息依法属于敏感个人信息。本服务处理此类信息具有特定目的（为孩子生成个性化练习）与充分必要性，并采取本政策第 7 条的严格保护措施。

5.2 **监护人单独同意：**
- **年龄如何判断：** 我们依据您提供的**孩子出生年份**判断是否不满十四周岁。为避免漏保护，判断采取**保守口径**——只要按年份推算"可能不满十四周岁"，即按不满十四周岁处理；未提供出生年份时，我们不会臆测，并会在需要时请您补充；
- 处理不满十四周岁未成年人的个人信息，我们取得其父母或其他监护人的**单独同意**：该同意在页面上**单独勾选**、**不与其他条款捆绑**、**不默认勾选**，并作为**独立的同意记录**单独保存，以便随时举证"单独同意"确已取得；
- 监护人同意机制支持**版本化管理**：每次同意的时间、版本、类型与范围均被记录；
- **您可随时获取您的同意记录**：通过【待填：隐私事务邮箱】索取，我们将在【待填：响应时限】日内提供；
- **您有权随时撤回同意**（操作路径见第 6.5 条），撤回不影响撤回前基于同意已进行的处理。撤回后，若孩子不满十四周岁，我们将同时停止相应处理直至重新取得单独同意。

5.3 **专门处理规则：** 针对未成年人个人信息，我们制定并执行专门规则：最小化收集、访问权限最小化、操作留痕审计、严格限制内部访问范围、禁止向未成年人推送任何商业信息。

5.4 **不用于个性化推荐与广告：** 孩子的学习数据、错题情况、能力画像**绝不用于**用户画像商业化、个性化推荐、算法营销或任何形式的广告。这是我们的一条底线，也接受您和社会的监督。

5.5 **不满十四周岁用户的账号：** 由监护人同意后代为注册或确认；监护人可随时通过第 6 条任一路径行使对相关信息的全部权利。

5.6 **已满十四周岁的未成年人：** 依《个人信息保护法》可自行同意一般信息处理；本服务仍建议并鼓励监护人参与管理，并保障其依法享有的查阅、更正、删除等权利。

5.7 **防沉迷提示：** 依据《生成式人工智能服务管理暂行办法》第十条，我们公开服务的适用人群与用途（见服务协议第 2.3 条），并提示您：本服务定位为每周轻量辅助练习，请合理安排孩子使用时间，防范过度依赖。

## 6. 您的权利与具体操作路径

以下权利，家长（监护人）均可行使；已满十四周岁的学生亦可就本人信息行使。

### 6.1 查阅
- 通过您的专属链接（免登录）随时查看孩子的错题本、报告与掌握度记录；
- 或发送邮件至【待填：隐私事务邮箱】，注明学生标识，我们将在【待填：响应时限】日内提供可查阅的内容。

### 6.2 复制
- 邮件至【待填：隐私事务邮箱】申请导出副本，我们会将报告与错题本以电子文件形式发送至您指定的邮箱。

### 6.3 更正
- **联系客服更正：** 发送邮件至【待填：隐私事务邮箱】或联系客服，说明需要更正的内容（如年级、教材版本、学习特质信息），我们核实后为您更正并回复确认；
- 涉及错题、答案、解析等 AI 生成内容的更正，您也可以直接在学习页使用「这题有问题」入口反馈，我们人工核对后处理。

### 6.4 删除（重要）
- **自助路径：** 在学生公开页底部点击「申请删除孩子学习数据」提交申请；
- **处理方式：** 运营方执行**级联硬删除**——学生档案及其错题、任务、文件、能力画像等全部个人数据一并从生产系统中彻底删除；
- **删除后保留：** 仅保留匿名化后的支付对账与审计记录（已无法关联到个人）；
- **生效时间：** 我们将在【待填：处理时限】日内完成删除，并通过您提交申请时提供的联系方式向您确认。

### 6.5 撤回同意
- 邮件至【待填：隐私事务邮箱】或通过客服渠道提交撤回声明；
- 撤回后，我们将停止相应的个人信息处理活动，并按 6.4 删除相关数据；撤回同意不影响撤回前已依法进行的处理。

### 6.6 注销账号
- 学生注册账号：发送邮件至【待填：隐私事务邮箱】申请注销，注明学生标识（如学生编号、注册昵称与年级），我们核实身份后将在【待填：处理时限】日内完成注销；
- 注销后账号不可恢复，相关数据按 6.4 的规则删除；
- 家长为免登录使用、无独立账号的，无需注销——申请删除孩子数据即等效实现全部退出。

### 6.7 响应说明
上述请求我们均在【待填：响应时限】日内处理完毕；对无合理理由重复申请、或涉及他人重大权益的，我们可能依规说明理由后拒绝，并告知您的救济途径。

## 7. 数据安全措施

7.1 传输加密：数据传输全程使用 HTTPS/TLS 加密。

7.2 存储安全：学生个人信息存储于受访问控制的数据库与对象存储中。我们采取网络隔离、账号最小权限、操作留痕审计、每日自动备份等措施保护数据，并限制内部人员仅在履职必需范围内访问。**我们的数据库与文件存储未启用全盘加密**，如未来启用将更新本政策并告知您。

7.3 访问控制：运营团队按最小权限原则访问数据，操作留痕可审计。

7.4 匿名化：对账与审计场景使用的数据先匿名化再留存。

7.5 安全事件：如发生个人信息泄露等安全事件，我们将依法及时向您告知，并向监管部门报告。
