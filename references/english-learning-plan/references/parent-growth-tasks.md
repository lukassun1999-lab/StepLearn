# 家长专属成长任务包（4周递进计划）

> 你以为这套系统只帮孩子成长？不，它也帮你成长。
>
> 很多家长跟我说："我只想让孩子学好英语，我自己不需要学什么。"但事实是——**孩子能不能坚持，80%取决于家长怎么陪。**不是陪得越多越好，而是陪得越"对"越好。
>
> 接下来4周，每周我会给你一个小任务。不需要花很多时间（5-10分钟），但需要你真的去做。每个任务背后都有心理学原理支撑——我会告诉你为什么这样做，以及怎么做才有效。
>
> 这些任务不是"监督清单"，而是帮你从"盯着孩子学的监工"变成"和孩子一起走的伙伴"。

---

## 第1周家长任务卡：🔍 观察者模式

**任务**：连续3天，每晚花1分钟，记录孩子做英语学习时的情绪状态。

**为什么做这个**：
> 心理学上有个概念叫"情绪标签"（affect labeling）——当你把模糊的感受变成具体的词，大脑的焦虑中枢就会降温。很多家长每天看到孩子学英语，心里会有一种说不出的焦虑，但从来没把它说出来。这个任务就是帮你把那个"说不出的东西"说出来。一旦说出来，它就不再那么可怕了。

**怎么做**：
```
【家长观察日记 · 第1周】
观察3天，每天1分钟，只用画表情：

第1天（日期：____）
孩子做英语时的情绪：😊 / 😐 / 😣
我的情绪：😊 / 😐 / 😣
我注意到的一件事：__________

第2天（日期：____）
孩子做英语时的情绪：😊 / 😐 / 😣
我的情绪：😊 / 😐 / 😣
我注意到的一件事：__________

第3天（日期：____）
孩子做英语时的情绪：😊 / 😐 / 😣
我的情绪：😊 / 😐 / 😣
我注意到的一件事：__________
```

**❌ 常见错误**：
- ❌ "你今天怎么又没背完？"（这是评判，不是观察）
- ❌ "你不背单词怎么考得好？"（这是恐吓，不是观察）
- ✅ 只是看，只是记，先不要干预——哪怕你急得想跳起来

**完成标志**：3天记录完毕，回来告诉我你的发现。

## 第2周家长任务卡：👂 非评判倾听

**任务**：本周找1次机会，让孩子说说对英语学习的感受。你只能回应"嗯""我听到了""还有吗"，不能给任何建议。

**为什么做这个**：
> 你有没有发现，孩子有时候跟你说"英语好难"，你的第一反应是"那你要多背单词啊"？这不是你的错，大多数家长都这样——我们太想帮孩子解决问题了。但很多时候，孩子说"难"，不是在求你给方案，而是需要你听见他。**被听见，本身就是力量。**当孩子感受到"我说什么爸妈都不会评价我"，他才会愿意说真话。真话，是我们调整计划的唯一依据。

**怎么做**：
```
【倾听练习 · 第2周】
时间：找一个孩子比较放松的时刻（如周末下午/睡前）
开场白："最近英语学得怎么样？随便说说，我就是想听听。"

你的工具箱（只允许用这3句话）：
✅ "嗯，我听到了。"
✅ "还有吗？"
✅ "嗯，然后呢？"

绝对禁用清单：
❌ "你应该……"
❌ "你看别人家……"
❌ "这有什么难的……"
❌ "你就是不够努力……"
❌ "我当年……"
```

**❌ 常见错误**：
- ❌ 孩子说"阅读好难"，你立刻说"那我给你买本阅读练习"（你跳过倾听，直接进入解决模式）
- ❌ 孩子说"我不想背单词"，你说"不背怎么行"（你在否定他的感受）
- ✅ 孩子说"阅读好难"，你说"嗯，阅读确实挺难的。还有吗？"（你在接纳，而不是评判）

**完成标志**：完成1次5分钟倾听，回来告诉我：你听到了什么？你忍住了哪些想给建议的冲动？

## 第3周家长任务卡：🤝 错误分析会

**任务**：和孩子一起看本周的1道错题，你负责问"你觉得卡在哪一步了"，不负责讲题。

**为什么做这个**：
> 传统模式下，家长看到错题的第一反应是"来，我教你"——但研究表明，**自己想明白的孩子，比被教明白的孩子，记忆深度差3倍。** 因为"想明白"的过程本身就是大脑在建立神经连接。你的角色不是"答案提供者"，而是"思维引导者"——用问题帮孩子找到自己的卡点。

**怎么做**：
```
【错误分析会 · 第3周】
准备：从本周错题中选1道孩子最有话说的题（不用选最难的，选最有讨论空间的）

步骤：
1. 开场："这道题你当时怎么想的？不用管对错，就说你的第一反应。"
2. 追问："那你现在觉得哪一步开始不对了？"
3. 继续追问："如果重新做，你会怎么想？"
4. 收尾："你觉得下次遇到类似的题，可以怎么做？"

你的定位：
✅ 提问者 —— 用问题引导孩子自己发现卡点
✅ 陪伴者 —— 让孩子感觉"有人和我一起面对"
❌ 讲解者 —— 不要代替孩子思考
```

**❌ 常见错误**：
- ❌ 孩子说"我不知道"，你立刻说"答案是C，因为……"（你抢走了他的思考机会）
- ❌ 孩子卡住了，你说"这么简单你都不会"（你在制造羞耻感，而不是安全感）
- ✅ 孩子说"我不知道"，你说"没关系，我们慢慢来。你觉得第一步是什么？"（你在给他台阶，同时推动思考）

**完成标志**：完成1次错误分析，回来告诉我：孩子自己找到了卡点吗？你有什么新发现？

## 第4周家长任务卡：🌟 优势发现者

**任务**：找出孩子本周英语学习中的1个具体进步点，用"行为+影响"的方式描述出来。

**为什么做这个**：
> 你有没有发现，我们很容易看到孩子"没做到的"，但很少看到孩子"做到了的"？这不是你刻薄，是大脑的"负面偏好"在作怪——大脑天生对问题更敏感。但孩子的成长需要"被看见"。不是空洞的"你很棒"，而是**具体的、可验证的、和行为绑定的肯定**。比如"周三你主动多背了3个单词"比"你真厉害"有效100倍——因为前者告诉孩子"我到底做对了什么"，后者只是模糊的夸奖。

**怎么做**：
```
【优势发现 · 第4周】
本周，留意孩子在英语学习中的1个进步瞬间。

描述公式：具体行为 + 带来的影响

❌ 模糊夸奖："你很棒！""你进步了！""继续加油！"
✅ 具体发现："我注意到你周三晚上主动多背了3个单词。这意味着你在建立自己的节奏——不需要别人催，你自己知道要做什么。我觉得这个比考多少分都重要。"

常见进步信号（不限于这些）：
- 主动提起英语相关的事
- 不用提醒就开始背单词
- 错题愿意看了（以前是逃避的）
- 口语树洞的时间变长了
- 说"这个我好像懂了"
- 问了一个关于英语的问题
```

**❌ 常见错误**：
- ❌ "你这次考得不错"（这是评价结果，不是发现行为）
- ❌ "你要是早点这样就好了"（你在否定过去，而不是肯定现在）
- ✅ "我注意到你今天做阅读的时候，碰到不认识的词没有直接跳过，而是查了意思。这说明你开始想搞懂了。"（这是看见具体行为+解读它的意义）

**完成标志**：找到1个具体的进步瞬间，回来告诉我：你看见了什么？你怎么跟孩子说的？
