# 阶段1：开场白 + 基本信息采集

## 开场白（AI自动发送）

```
你好，欢迎你来这里。😊

我想先跟你说一句话——你愿意花时间帮孩子做这件事，已经很了不起了。很多家长都想帮孩子，但迈不出这一步，而你做到了。

接下来的12分钟，我不是来给你发模板的，也不是来给你布置任务的。我是想和你一起，基于孩子的大脑怎么学、心里怎么想，来定制一套真正属于他的方案——一套他愿意做、能坚持、既能提分又能慢慢长出自主学习能力的成长计划。

我会先问你几个问题，了解孩子的基本情况；最后也会请孩子来回答3个小问题。这个过程像聊天，是我们一起画一张孩子的画像，让计划真正从他心里长出来，而不是硬套上去。

准备好了吗？我们慢慢来，不赶。
```

## 第一部分：我们先从了解孩子开始

这些问题都不复杂，你如实回答就好。每一个答案都会让后面的计划更贴近孩子的真实情况，所以没有什么标准答案——你的孩子就是最好的标准。🌱

**Q1.1** 孩子的姓名/昵称？

> 这个名字会出现在计划的每一页上，是我们为ta量身定制的专属称呼。你可以用大名，也可以用小名——怎么舒服怎么来。

**Q1.2** 男孩/女孩？

> 匹配更合适的称呼和学习节奏

**Q1.3** 年级+上/下学期？核心升学目标是什么？

> 不用觉得"目标一定要宏大"，哪怕是"先稳住不下滑"也是一个很真实、很珍贵的目标。告诉我孩子现在在哪里，以及你想陪ta走到哪里就好。

**Q1.4** 选科情况？

> 文科/理科/未分科；未分科请说明更偏向文科（历史/地理）还是理科（物理/化学）

**Q1.5** 住校/走读？

> 住校和走读的孩子，学习节奏差别很大。告诉我真实的情况，我们才能设计出"在孩子生活里自然生长"的计划，而不是"理想状态下的幻想"。

* 住校：周五几点到家、周日几点返校？
* 走读：每天几点到家、晚上一般学到几点？

**Q1.6** 学校使用的英语教材版本？

> 例如：人教版必修2、外研版、译林版
